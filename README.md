# Calvinstools Food Trailer

Modern soft-white React food trailer landing page.

## Run

```bash
npm install
npm start
```

Then open http://localhost:3000

## Structure

Each major section is separated into its own component and CSS file.

- Navbar
- Hero
- Marquee
- About
- Menu
- Stats
- Location
- Reviews
- Catering
- CTA
- Footer
